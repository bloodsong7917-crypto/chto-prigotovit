# Что приготовить

Приложение для Android: подбирает рецепты из продуктов, которые есть дома, составляет рацион и помогает считать калории.

- **Продукты** — список вводится вручную или распознаётся по фото.
- **Рецепты** — блюда по списку продуктов или сразу по фото, на нужное число порций, с калориями и БЖУ.
- **Рацион** — меню на день или неделю на 1–12 человек со списком покупок.
- **Калории** — суточная норма (формула Миффлина — Сан-Жеора) и дневник съеденного; калорийность блюда можно оценить по описанию или фото.

Распознавание фото и подбор блюд работают через Google Gemini API. Ключ (бесплатно на <https://aistudio.google.com/apikey>) вводится в настройках приложения и хранится только на телефоне.

 Минимальная версия Android — 8.0.
